# UU-REA 首版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 让鸿蒙电脑通过官方UU协议连接并操作用户自己的Mac Studio。

**Architecture:** ArkTS原生网络桥处理禁止重定向的HTTPS与Socket.IO polling；内嵌可信本地ArkWeb页面处理WebRTC和输入。Mac继续运行官方UU被控客户端，不替换被控端。

**Tech Stack:** ArkTS Stage、ArkWeb、NetworkKit、WebRTC、TypeScript、Vite、MIT协议参考。

**Spec:** [首版范围与技术路线](./2026-10-17-首版范围与技术路线.md)

## Global Constraints

- 鸿蒙电脑作为主控，直接与用户自己的官方网易 UU Mac 客户端互通。
- 不以自建屏幕采集/输入注入 Mac 被控程序替代用户要求。
- 凭据不写文件、源码、日志或Git；开发期会话仅内存，签名材料由平台密钥库提供。
- 首个工程使用本机SDK构建；设备API兼容性在连接真机后核对，不声称已支持全部版本。
- 模拟、构建、信令、画面、鼠标、键盘的证据分别记录。

## Review Focus

- 认证信息不能因错误处理、导出、浏览器存储或日志泄露。
- 原生网络桥不能成为访问任意主机的通用代理。
- WSS打开与Socket.IO连通、媒体到达与可解码必须分别判断。
- Mac键码、鼠标坐标缩放、连接中断与按键释放需有协议/状态检查。
- 设备未接入、未签名或协议材料缺失时显示实际未完成状态。
