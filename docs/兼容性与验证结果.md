# 兼容性与验证结果

截至 **2026-10-20（Asia/Shanghai）**。本文区分已运行版本、离线检查和未验证能力，供使用者判断适用范围、维护者安排复测。
项目概览、构建和首次运行见 [README](../README.md)，实现约束见[架构与安全边界](架构与安全边界.md)。

网络、官方客户端版本和 UU 服务节点变化后，需要重新验证；下文通过次数是对应轮次的观察值，不是长期成功率承诺。

### V5：受控信令故障恢复

在媒体建立并取得恢复 key 后，探针令一次 polling GET 失败：恢复约 **513ms**，原 Peer 和媒体会话保持，未重新 JOIN/control/offer。
该轮媒体跨度 130,005ms、2,537 有效帧增长、14 个样本，发生 1 次恢复；正常退出通过。
恢复后再次实际完成鼠标聚焦、数字显示和删除清空，未用按键发送日志代替接收结果。

这是**受控信令请求失败**，不是拔网线、关闭 Wi-Fi、休眠唤醒或真实物理断网验收。
V5 仅用于测试，随后已被无故障钩子的基准包替换；探针结果不能表述为基准包在任意断网条件均可恢复。

| Mac，2026-10-20 队列隔离候选（HAP 摘要 `ad9cd677…`） | 固定 20 轮仅 10 成功、10 失败，包含首帧前失败和出画后超时；未删除或用后续成功替换。 |
| Windows，2026-10-17 至 18 验证版本 | 曾实际完成画面、鼠标及计算器键盘输入；保留分段的同版三次普通连接首帧 3/3，但其中长轮仍心跳断线，持续连接 FAIL。 |

Windows 兼容路径仅对 Windows 开启候选 FIFO 分段：保留原顺序，连续普通候选合批、relay 候选分别 POST；Mac 沿用原批次。候选含 relay 不等于强制中继。
历史 Windows 数据未覆盖后续 Mac 稳定性修复版本的完整复测，不能将 Mac 的 20 分钟/20 轮结果套用于 Windows。
目前未对每次心跳中断归属 UU 服务端、网络路径或平台传输层作出完整证明。

## 反向被控能力边界

独立本地探针曾在 API23 模拟器获得用户授权，跨应用鼠标切换系统设置页面、键盘输入在另一个应用实际得到 `7+8=15`，输入能力 PASS。
同模拟器原始屏幕取帧未取得有效帧，NDK H.264 编码未取得编码器或可解码输出，媒体链路 FAIL。
云端鸿蒙电脑虽然有安装/启动与用户授权观察，尚无可归属探针的有效帧、编码字节及可解码样本，云媒体仍为 UNKNOWN。
这些探针没有接入 UU 被控协议；云平台自身的远控画面不能算本产品采集成功，也不能算官方 UU 反向控制通过。

## 如何复测与记录

1. 先按 [README](../README.md) 准备环境并执行 [`scripts/check-all.sh`](../scripts/check-all.sh)、完整构建；记录提交、HAP 指纹、运行系统、被控端版本和网络条件。
2. 确认双方为本人账号、目标允许控制；从无活动远控会话开始，核对实际目标后正常连接，不自动强制接管已有会话。
3. 将“信令就绪、首帧、媒体持续推进、鼠标结果、键盘结果、清理”分别记录。视频轨道、SDP 或 FIRST_FRAME 单独出现不等于持续可用。
4. 长连接观察同一 Peer 的播放时间和总帧减丢弃帧增长；每 10 秒取样，记录恢复、重试及错误，禁止换会话补足时长。
5. 重连按固定轮数串行执行，每轮完成媒体检查后正常退出，确认上一房间已清理且主页恢复可连接，再开始下一轮；保留全部失败和内部重试。
6. 鼠标、键盘以远端受控测试内容的实际变化验收，结束后清除测试输入。退出应释放持有键鼠、停止媒体与计时任务，并确认本次拥有的房间已释放；清理失败先重试清理，不继续新一轮。

离线最近检查为 Web 138 项、原生 policy 229 项、transport 81 项、signing 32 项及 session 适配检查通过；它们是离线结果，不是新版本实机验收。
复测日志只保留固定阶段、数字错误、媒体计数和清理结果；Token、手机号、验证码、签名材料、房间凭据、SDP/candidate 原文不得落盘或进入截图。
公开记录使用受控无敏感内容的接收端结果，私人桌面和原始研究不随仓库分发。没有实际观测的能力保留 UNKNOWN。

尚未覆盖鸿蒙实体电脑、真实物理断网、弱网/休眠唤醒、完整多节点轮换、中文/IME、剪贴板、音频与多屏切换。
